# Исправления согласно замечаниям ментора

## Обзор исправлений

Данный документ описывает все исправления, внесенные в проект согласно замечаниям ментора @dmievlev.

## 1. Архитектурные изменения

### 1.1 Объединение сервисов в единый shop сервис
- **Было**: Отдельные сервисы для auth, cart, catalog, orders
- **Стало**: Единый shop сервис с методами для всех операций
- **Файлы**: 
  - `src/backend/services/shop/service.py` - основной сервис
  - `src/backend/services/shop/adapter.py` - адаптер для HTTP запросов
  - `src/backend/services/shop/models/` - модели данных

### 1.2 Реструктуризация HTTP клиента
- **Было**: Монолитный HTTP клиент с избыточными allure.step
- **Стало**: Модульная структура согласно архитектуре ментора
- **Файлы**:
  - `src/backend/clients/http_client/client.py` - основной клиент
  - `src/backend/clients/http_client/utils.py` - утилиты для allure
  - `src/backend/clients/http_client/constants.py` - константы
