# Домашнее задание 3: Основы Python

В этой директории находятся решения задач по модулю "Python Basic".

## Темы и задачи

1. **args_kwargs**:
   - `task_1_sum_all.py`: Функция, которая суммирует все переданные числа через *args.
   - `task_2_greet.py`: Функция для приветствия пользователя с использованием **kwargs.

2. **built_in_functions**:
   - `task_1_squares_map.py`: Возведение чисел в квадрат с использованием функции map.
   - `task_2_filter_even.py`: Фильтрация чётных чисел через filter.
   - `task_3_sort_words.py`: Сортировка слов в строке.
   - `task_4_square_odds.py`: Квадраты нечётных чисел.
   - `task_5_product.py`: Произведение всех чисел в списке.
   - `task_6_count_words.py`: Подсчёт количества слов в строке.
   - `task_7_normalize_whitespace.py`: Удаление лишних пробелов.
   - `task_8_make_sentence.py`: Построение предложения из списка слов.
   - `task_9_merge_lists.py`: Объединение списков без повторений.
   - `task_10_pop_until_zero.py`: Удаление элементов из стека до нуля.
   - `task_11_double_dict_values.py`: Удвоение значений в словаре.
   - `task_12_filter_dict_by_value.py`: Фильтрация словаря по значению.
   - `task_13_sort_people_by_age.py`: Сортировка списка людей по возрасту.
   - `task_14_sort_dict_keys.py`: Сортировка словаря по ключам.
   - `task_15_process_numbers.py`: Обработка списка чисел (фильтр + map + sum).

3. **classes**:
   - `task_1_car.py`: Класс "Машина" с методами запуска и остановки двигателя.
   - `task_2_rectangle.py`: Класс "Прямоугольник" с методами сравнения и вычисления площади.

4. **context_managers**:
   - `task_1_file_writer.py`: Менеджер контекста для записи в файл.
   - `task_2_time_tracker.py`: Менеджер контекста для замера времени выполнения кода.
   - `task_3_list_context.py`: Менеджер контекста для временного изменения списка.
